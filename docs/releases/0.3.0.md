# 0.3.0：可选紧凑触控视觉

## 评审与 API

接受“视觉紧凑程度与输入模式分离”的通用需求。增加 `IanvsTouchVisualDensity { standard, compact }`，由 `IanvsTheme.build/light/dark(touchVisualDensity: ...)` 选择，默认 standard。启用 compact 时仍需 `density: IanvsDensity.touch`；`IanvsDensity` 没有新增成员，已有移动导航判断和穷尽 switch 保持兼容。Tokens 暴露 `touchVisualDensity` 和 `isCompactTouch`。

紧凑模式使用16点正文/输入、18/17点标题、13点辅助/堆叠标签、20点普通及动作图标。`Theme.of(context).iconTheme.size` 可供宿主读取；按钮样式也配置20点图标。普通字段最小44点，列表和菜单最小48点；Material 按钮外观最小44点、padded 交互布局至少48点。`IanvsFieldRow` 仅在堆叠布局中使用13点标签与4点标签间距。

实际验证发现 ListTile 的纵向 contentPadding 会叠加到最小行高之外，紧凑模式去掉这层额外纵向 padding，使普通单行实际达到48点。整数步进器为按钮48点交互布局预留宽度，输入最小44点。尺寸都是最小值，文字放大后允许增长。

不整体缩小导航栏/底栏，不迁移 Trail 的 SSH 分组、业务优先级、回放控制、路由或持久化。独立代码/终端排版不随新选项缩小。原 touch、macOS compact、Android 默认行为保持兼容；其他平台可主动选择新的通用 touch 视觉样式。详细接入约束见 `docs/integration.md`。

## 验证

- `flutter analyze` 无问题，Dart 格式与 diff 检查通过。
- 库114项、展厅70项，共184项测试通过。
- 新增21项回归：375/402点竖屏、844×375横屏 × 深浅色 × 1/2/3倍文字；402点场景含300点键盘区域，验证输入、滚动、保存及错误说明布局。
- 验证普通按钮44点外观和48点外部布局、普通输入44–48点、图标输入至少48点、普通列表48点，并验证大字时自然增高。
- 选择控件、图标、菜单与步进器通过 iOS 触达语义检查，步进和菜单选择回调可用。
- Web 与 macOS release 构建成功。

只读参考提供的 Trail 设计说明和概念图，没有操作共享桌面、Simulator、真机或 Trail 工作区。Flutter 离屏回归不替代原生 iPhone 字体显示、VoiceOver 或业务流程验证，宿主继续承担这些验收。
