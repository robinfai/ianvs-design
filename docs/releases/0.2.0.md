# 0.2.0：ACP 共用能力评审与验证

## 接受的通用能力

- **等宽文字主题**：ACP 的文件路径、代码块、工具输出重复维护字体族和排版。新增 `IanvsTypography` 主题扩展，提供随主题变化、可覆盖字体的 `code` 样式；终端和代码渲染器也可读取其字体属性。
- **受控尺寸调整手柄**：侧栏和底部/右侧面板共享拖动、边界、重置和无障碍交互。新增 `IanvsResizeHandle`，仅发出尺寸请求，支持两个轴与物理反向。
- **输入集成契约**：`IanvsTextField` 已能透传外部 controller、FocusNode、回调和表单属性。补充代理组合说明与契约测试，无需增加第二套输入代理。

## 留在宿主的能力与理由

- 不新增整个多面板工作区容器：ACP 已有布局预算、断点、会话树、Inspector、终端和显隐状态；抽取这些会耦合业务并影响草稿生命周期。宿主可把共享手柄嵌入现有 Row/Column，`IanvsWorkspace` 保持兼容。
- 不迁移 macOS AppKitView/MethodChannel 代理：其 view type 注册、语义开启时机、原生输入同步和代际清理依赖宿主原生工程。普通 `labelText` 不能替代该能力。
- 不统一聊天正文、语法高亮和 ANSI palette：阅读字号与消息、代码、终端颜色拥有各自业务含义，继续由 ChatTheme 等宿主主题持有。

## 验证

- `flutter analyze`：无问题。
- 库 `flutter test`：82项通过，包括横/纵向、正/反向拖动、边界、键盘、语义增减、重置、拒绝更新、禁用及外部焦点所有权。
- 示例 `flutter test`：70项通过，包括实际面板尺寸变化、显隐和窄窗下的草稿保留，以及现有明暗主题、200%文字与组件交互回归。
- `flutter build web --release --no-web-resources-cdn`：成功，Wasm 预检也成功。
- `flutter build macos --release`：成功。

本次只读参考 ianvs-acp，没有修改其工作区。原生 VoiceOver 名称、AppKit 代理生命周期及真实 ACP/终端业务仍需宿主集成验证；本库的 Flutter 测试不声称覆盖原生代理。
