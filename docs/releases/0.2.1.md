# 0.2.1：iOS 触控排版与表单回归

## 评审结论

- 修复库内可复现的问题：`IanvsFormSection` 在 390 点视口、长中英文标题与操作文字组合下发生横向溢出。窄屏或大字号时改为上下排列，宽屏限制操作宽度，公开 API 保持兼容。
- iOS 原生字体使用 Flutter Cupertino Typography 提供的 Text/Display 字体入口，避免沿用 macOS 字体入口；宿主显式字体配置继续优先。
- 显式 `iOS + IanvsDensity.touch` 使用 17 点正文和操作、15 点次要文字、13 点注释和输入帮助文字。系统 `TextScaler` 继续生效，macOS compact 与 Android 排版保持原有尺寸。
- 现有 touch 模式已提供 48 点控件、56 点列表行和足够的选择控件触达区域，本次补充验证，不另建一套移动组件。

## 宿主接入边界

Trail 尚未使用本库时出现的旧界面问题，不能作为本库缺陷的证据。本次只读参考宿主主题，没有修改 Trail 工作区，也没有操作 Simulator 或共享桌面。

宿主需显式选择 touch 密度，提供页面边距、SafeArea、可滚动表单与键盘避让；固定底部操作、业务导航、SSH、同步和持久化仍由宿主负责。接入示例见 `docs/integration.md`。

## 验证

- `flutter analyze`：无问题。
- 库 `flutter test`：93 项通过；其中新增 11 项覆盖 iOS 深浅色、1–3 倍文字、长标签与操作、触达语义检查、键盘区域上方的对话框操作及桌面标题排列。
- 示例 `flutter test`：70 项通过。
- `flutter build web --release --no-web-resources-cdn`：成功。
- `flutter build macos --release`：成功。

这些离屏测试验证 Flutter 布局、语义尺寸与交互，不替代原生 iPhone 字体显示、VoiceOver 和 Trail 业务流程的实际验收；原生截图验证由宿主任务继续完成。
