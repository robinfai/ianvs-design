# Ianvs Design Gallery

macOS / Web 组件展厅，包含明暗主题、三档密度、组件搜索、状态交互和代码示例。详细说明见[组件库 README](../README.md)。

## 运行

执行 `flutter pub get`，然后 `flutter run -d macos`。

Web 预览：`flutter run -d web-server --web-hostname 127.0.0.1 --web-port 4173`。

默认展示深色连接设置。表单保存是内存演示，不连接真实进程或服务。⌘K / Ctrl+K 搜索组件，顶部菜单切换浅色、深色或系统外观。

示例字体按 SIL OFL 分发，授权文本随资源打包并注册于 Flutter LicenseRegistry；它们不属于基础库依赖。
